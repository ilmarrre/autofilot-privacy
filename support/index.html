Start with one folder

  1. Scan a folder

    Choose a folder such as Downloads and allow access in the macOS folder picker. Scanning does not move your files.

  2. Connect your projects

    Choose a work folder that contains your existing project folders. Autofilot uses that structure when preparing destinations.

  3. Review the plan

    Check each file and its proposed destination. For an unresolved item, choose a folder or create one inside the right project.

  4. Move approved files

    Confirm only the moves you want to make. Check the result in the destination folder.

  5. Use Undo if needed

    Open History and choose Undo for the move. Start with disposable sample files when learning the workflow.

Common questions

Why does Autofilot ask for folder access?

macOS requires your permission to read and move files in selected folders. If access stops working, choose the folder again in Autofilot Settings. Removing access does not undo earlier moves.

Why is a file waiting for review?

The destination may be unclear. Open the plan, check the project, and choose or create the destination folder yourself before approving a move.

Can every move be undone?

Undo needs access to the file and its original location. If the file changed or the original path is occupied, Autofilot reports a conflict instead of overwriting another file. Keep your own backups.

Is a subscription required?

The App Store version requires an active subscription for scanning, work-folder analysis and file moves. Plans and any eligible introductory offer appear in the app. Use Restore purchases with the Apple Account used to subscribe. Existing history, search, Undo and folder-access settings remain available after expiry.

Where can I read about my data?

The local organization workflow processes the folders you select on your Mac. Read the privacy policy for information about data handling and contacting us about privacy.
